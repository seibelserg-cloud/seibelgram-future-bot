# SEIBELGRAM FUTURE CARS — автоматический TikTok

Актуально на 13 ноября 2026 года.

## Режим публикации

По решению владельца обязательный AI-контроль качества изображения **отключён**.
Бот публикует первый технически исправный сгенерированный автомобиль. Он не ждёт
подтверждения, что дизайн достаточно футуристичен, геометрия идеальна или
отсутствуют случайные эмблемы. В промптах просьба не создавать логотипы и
надписи сохранена, однако отсутствие таких элементов не гарантировано.

- **12:30 Europe/Berlin** — основная публикация, генерация запускается заранее.
- **19:00 Europe/Berlin** — резервная публикация, только если утром пост не был зарезервирован.
- **Максимум один ролик в сутки**, чтобы не засорять TikTok дублями.
- В каждом запуске генерация пытается создать два изображения на Cloudflare Free.
- Выбирается первый исправный JPEG. Отдельная онлайн-проверка Cloudflare Clef не вызывается.
- Создаётся девятисекундный вертикальный MP4 с оригинальным синтезированным звуком без текста на кадрах.
- Изображение, ролик и уникальная блокировка публикации сохраняются в GitHub **до** одного запроса Buffer.
- Отправляется описание с AI-generated маркировкой. Неизвестный результат Buffer не повторяется автоматически.

## Какие проверки остались

Только техническая целостность: наличие и читаемость JPG, достаточное разрешение,
корректный вертикальный кадр 1080×1920, отсутствие точного повтора уже
использованного изображения и не более одной публикации за день.
Эти проверки нужны, чтобы система отправляла действительные файлы без дублей.
Оценка красоты, оригинальности и конструкции автомобилей **не блокирует публикацию**.

## Где смотреть результат

В GitHub:
https://github.com/seibelserg-cloud/seibelgram-future-bot/actions

- Workflow `SEIBELGRAM — safe generator`, задание `daily_candidate_qa`.
- Артефакт `seibelgram-daily-image-candidates` — созданные изображения.
- Артефакт `seibelgram-auto-post-status` — запись о созданном MP4 и Buffer-попытке.
- Workflow `SEIBELGRAM — TikTok delivery audit` — отдельная вечерняя проверка конечного статуса.

Важно различать: успешный GitHub Actions → Buffer принял задачу
(`BUFFER_ACCEPTED`) → Buffer подтвердил `sent` → ролик можно проверить в TikTok.
Один зелёный GitHub run сам по себе не доказывает публикацию.

Отдельный мониторинг ChatGPT активен ежедневно на **21:30 Europe/Berlin**.

## Ограничения

Если Cloudflare не создал ни одной картинки, Buffer не принял запись или
возникла ошибка GitHub, гарантировать ежедневную публикацию нельзя.
Используются существующие бесплатные лимиты; платные сервисы не включены.
Никакие токены не нужно выкладывать в репозиторий или сообщать в чате.
