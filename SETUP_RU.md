# SEIBELGRAM FUTURE CARS — управление ботом

Обновлено: 13 ноября 2026 г.

## Что подключено

- Cloudflare Workers AI Free (FLUX.2 klein 9B + Clef для проверки).
- GitHub Actions: запуск генерации дважды в день.
- Buffer GraphQL: проверена связь именно с TikTok **@seibelgram**.
- Публично отправлены два отдельных разовых тестовых поста 8 и 9 ноября 2026 года.

## Автопубликация после включения ветки main

Бот делает **до двух попыток публикации в день**, а не гарантированные два поста.
GitHub запускает два цикла заранее, а Buffer ставит одобренные ролики на:

- 12:30 Europe/Berlin
- 19:00 Europe/Berlin

По каждому запуску:
1. Генерируются два разных концепт-кара за счёт доступной квоты Free.
2. Техническая проверка + независимый онлайн-фильтр Clef проверяют качество, геометрию, отсутствие логотипов и повторов.
3. Если ничего не прошло проверку, пропускаем слот. Требования к качеству автоматически не снижаются.
4. Для принятого изображения создаётся 9-секундный вертикальный MP4 H.264/AAC с оригинальной электронной звуковой дорожкой, без надписей на кадрах.
5. Оригинал изображения, MP4 и защита от повторного постинга сохраняются в GitHub.
6. Только после этого отправляется **один** запрос в Buffer с меткой AI-generated и точным временем публикации.

## Как проверить

Открой [GitHub Actions](https://github.com/seibelserg-cloud/seibelgram-future-bot/actions), выбери запуск **SEIBELGRAM — safe generator**.

Внутри смотри задание `daily_candidate_qa`:
- `Generate separate image candidates` — генерация.
- `Run real visual QA` — оценка и причины отказов.
- `Prepare ONE original-sound...` — создание ролика при успешном QA.
- `Queue once in Buffer...` — одна попытка планирования.
- `seibelgram-auto-post-status` — журнал решения и квитанция.

Зелёный статус GitHub Actions означает успешный запуск задания, **не обязательно публикацию**. Статус `BUFFER_ACCEPTED` означает принятие задачи Buffer, а не окончательную публикацию в TikTok; её необходимо подтвердить по Buffer/TikTok.

## Важные ограничения

- Качество FLUX.2 Klein 9B недостаточно надёжно для гарантированных двух постов ежедневно. Реальная проверка 13 ноября отвергла оба изображения.
- Если Buffer недоступен или ответ неизвестен, повторной автоматической отправки **не будет**.
- Подписки на платные сервисы, тариф Workers Paid и коммерческая музыка **не включены**.
- Не сохраняй API-ключи в файлах или сообщениях чата; они должны оставаться в GitHub Actions Secrets.
